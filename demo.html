Things to know

  • Authentication: login / signup / password reset / email verification are all wired up.
  • Route safety: every public page returns HTTP 200; every logged-in page redirects to login (307) instead of crashing — no 500s on load.
  • Data volume: the connected database is lightly populated (5 users, 5 jobs, 8 orders, 3 adverts). Profiles, products, companies and projects have no records yet — so those sections will show "empty state" until you add content.
  • Still to seed: taxonomy terms, news ticker, notifications and profiles are empty — content-driven pages will look bare until data is added.
